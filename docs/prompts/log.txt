실시간 렌더링: FastAPI의 SSE를 수신하여 st.write_stream 기능을 통해 AI의 사고 과정을 실시간으로 화면에 출력하십시오.

4. 작업 규칙 및 협업 가이드 (Core Rules)
One-Codebase: 모든 로직은 /Users/joonbinchoi/Work/MaterTask 내에서 동작해야 하며, 서로의 소스 경로를 참조할 수 있도록 설정하십시오.

No-Auth: 모든 API 요청에서 Authorization 헤더 및 UserID 검증 로직을 제거하고, 기본 tenant_id=1, user_id=1로 하드코딩하여 PoC의 편의성을 높이십시오.

DB Integrity: 기존 DB 스키마를 수정하지 말고 그대로 사용하되, 부족한 필드는 Python 레벨에서 Mocking 처리하십시오.

Stream-First: 사용자가 "분석 시작" 버튼을 누르면 AI가 생각하는 과정이 끊김 없이 출력되도록 비동기(asyncio) 처리를 최우선으로 하십시오.
