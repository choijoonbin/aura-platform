현재 기준으로 “완료”까지 남은 건 크게 4단계입니다.

P1 안정화 마감
v2가 legacy fallback 없이 안정 동작
shadow KPI(verdict_match/score_delta/citation_coverage_delta) 값 정상 집계
탭 간 runId/caseId 정합성 100%
P2 Agentic 본체 전환
finance_aura_v2_agentic를 LangGraph 노드/툴 자율선택 기반으로 고정
AGENT_EVENT 중심 스트림 운영(기본/디버그 2단)
P2.5 성능·품질 게이트 고정
Shadow Run 기준선 충족(정확도/근거연결률/보류율/지연)
Go/No-Go 조건 2주 연속 통과
P3 점진 스위칭 완료
feature flag로 canary → 점진 확대 → 기본 경로 전환
전환 후 legacy는 fallback 전용으로 유지
즉, 실질적으로는 “안정화 1단계 + 전환 3단계” 남았습니다.
